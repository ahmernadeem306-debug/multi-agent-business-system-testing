# BizAgent AI: Multi-Agent Supermart Operations Assistant

BizAgent is a stateful, production-ready multi-agent operational framework engineered for retail supermart environments. It automates root-cause analytics over store inventory thresholds and company corporate policy contracts.

## 🚀 Core Architectural Stack
- **State Logic Engine:** LangGraph (StateGraph Workflow Infrastructure)
- **Local DB Storage Layers:** SQLite3 Parameterized Engine
- **Vector Intelligence Matrix:** ChromaDB Contextual Processing Vector Space
- **User Interface Gateway:** Streamlit Data Portal

## 🛠️ Step-by-Step Installation Operations

1. **Clone project directory structure locally:**
   ```bash
   git clone https://github.com
   cd BizAgent
   ```

2. **Configure operational dependencies variables:**
   ```bash
   pip install streamlit langchain-openai langgraph chromadb pypdf python-dotenv
   ```

3. **Initialize Environmental Key Security Barrier:**
   Create a local system configuration `.env` file in the main folder root level and safely append your orchestration key inside it:
   ```env
   OPENAI_API_KEY=your_secured_openai_api_key_here
   ```

4. **Boot up Enterprise Live Dashboard Console:**
   ```bash
   streamlit run app.py
   ```

5. **Runtime Data Lifecycle Ingestion:**
   Upon successful user interface gateway log-in (`Username: admin | Access Key: supermart2026`), navigate straight towards the sidebar interface blocks to upload your local structural products `.csv` layout file and compliance policy manual `.pdf` assets dynamically into memory.
